# 12. Тестирование

## Уровни

| Уровень | Что | Инструменты |
| --- | --- | --- |
| Unit (Go) | Нормализация ссылок, сборка подписи, проверки прав, лимиты, очередь (аренда, повторы, дедуп), LRU кэша, сопоставление ошибок yt-dlp, выбор формата | `testing`, табличные тесты, векторы `internal/shared/urls/testdata/vectors.json` |
| Интеграция ядра | REST API на реальной SQLite во временном файле; gRPC с фейковым воркером; приём файлов с докачкой | `httptest`, in-process gRPC (`bufconn`) |
| Интеграция воркера | Воркер против фейкового ядра и фейкового Telegram; yt-dlp подменяется скриптом-заглушкой с фиксированным JSON и файлом | `httptest`, `testdata/fake-ytdlp` |
| Сквозные (локально) | `make dev`: ядро + воркер + фейковый Telegram API в compose; сценарии резолв → скачивание → отправка | Go-тесты с тегом `e2e` |
| Живые платформы | Ручной прогон по реальным ссылкам TikTok и Reels с сервера воркера; не в CI | `make smoke-live URLS=...` |
| Android unit | ViewModel'и, извлечение ссылки из интента, маппинг ошибок, логика кнопок sheet | JUnit, Turbine, MockWebServer |
| Android UI | Sheet «Видео» во всех состояниях, «Куда отправить», онбординг | Compose UI tests, скриншот-тесты (Roborazzi) против макетов |

## Фейковый Telegram API

`internal/devtools/faketelegram` (бинарник `cmd/faketelegram`, используется и стендом `make dev`): HTTP-сервер, реализующий нужные методы Bot API (`getUpdates`, `sendMessage`, `sendVideo`, `getChatMember`, `getChat`, `setMyCommands`) с управляемым состоянием: участники чатов, права, ошибки 403/429. Воркер в тестах получает `bot_api_base` на него через `Config`.

## Критерии приёмки

### Приём ссылки и превью
- [ ] Через «Поделиться» из TikTok и Instagram открывается sheet с превью для 10 из 10 тестовых публичных видео
- [ ] Короткие ссылки `vm.tiktok.com`, `vt.tiktok.com`, `tiktok.com/t/` резолвятся в тот же `video_id`, что и полные
- [ ] Повторный резолв того же видео в течение суток не создаёт задачу воркеру
- [ ] Неподдерживаемая ссылка, сторис, карусель, приватное видео — понятная ошибка, без зависания

### Скачивание
- [ ] Файл сохраняется в `Movies/Quoker`, воспроизводится, виден в галерее
- [ ] TikTok скачивается без водяного знака
- [ ] Обрыв сети на середине — докачка продолжается с места обрыва
- [ ] Закрытие sheet не прерывает скачивание; уведомление показывает прогресс и результат

### Отправка
- [ ] Видео доставляется в канал, группу и личку бота; подпись по умолчанию — ссылка на оригинал
- [ ] В группе по умолчанию добавляется «от @username»; переключатель отключает; в канале подписи автора нет
- [ ] Ролик больше 50 МБ отправляется в пониженном качестве или даёт `too_large`
- [ ] Повторное нажатие «Отправить» с тем же ключом не дублирует сообщение
- [ ] Обрыв воркера во время отправки не приводит к двум сообщениям в канале

### Изоляция пользователей
- [ ] Второй пользователь не видит цели первого; отправка в чужой `target_id` — 403
- [ ] Пользователь, вышедший из группы, теряет возможность отправлять в неё в течение 5 минут
- [ ] После удаления бота из канала цель становится неактивной с причиной
- [ ] Заблокированный пользователь теряет доступ на всех устройствах сразу

### Воркер и инфраструктура
- [ ] Перезапуск воркера во время задач: задачи доделываются после переподключения
- [ ] Замена воркера по ранбуку укладывается в 30 минут, данные и пользователи не затронуты
- [ ] Переключение на REALITY и обратно не требует изменений на ядре, кроме профиля
- [ ] Отозванный воркер отключается в течение минуты и не может переподключиться
- [ ] Апдейты бота не теряются при перезапуске опрашивающего воркера
- [ ] Восстановление ядра из бэкапа с ПК проходит, данные консистентны

### Обновления и админка
- [ ] Новая версия APK предлагается в приложении, ставится поверх, данные сохраняются
- [ ] Версия ниже минимальной блокируется экраном «Обновите приложение»
- [ ] Админ создаёт инвайт в приложении и через бота; инвайт одноразовый и истекает
- [ ] Обновление cookies Instagram через бота доходит до воркера без перезапуска
- [ ] Алерты: нет воркеров, рост ошибок, диск, истечение сертификата — приходят админу
