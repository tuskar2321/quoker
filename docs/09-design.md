# 09. Дизайн

Утверждённые макеты: `docs/design/mockups/*.dc.html` (размер 390×844, открываются в браузере как разметка; `support.js` к ним не прилагается — используйте их как точный референс размеров, отступов, текстов и цветов). Логотип: `docs/design/logo.svg`, монохромная иконка для уведомлений: `docs/design/icon-notification.svg`.

## Принципы

- Только тёмная тема, чистый чёрный фон (AMOLED). Dynamic color не используется.
- Два акцента со смыслом: **лайм — скачивание**, **голубой — Telegram**. Других акцентов нет.
- Крупные кнопки действий (56 px), sheet поверх исходного приложения, минимум текста.

## Логотип и иконка

- Знак — лаймовая лягушка (`logo.svg`), словесный знак «quoker» строчными, Manrope 800.
- Иконка приложения: adaptive icon, фон `#141414`, передний план — знак на 66% safe zone; монохромный слой для тематических иконок Android 13+ — `icon-notification.svg`.
- Инверсия (тёмная лягушка на лайме) — для мест, где знак стоит на лаймовом фоне.
- Иконка уведомлений — `icon-notification.svg`, белая, без деталей.
