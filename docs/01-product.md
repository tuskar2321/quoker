# 01. Продукт

## Назначение

Quoker избавляет от рутины «скачать ролик из TikTok или Reels и переслать его в свой канал или чат». Ссылка попадает в приложение через системное меню «Поделиться» или вставкой; дальше две независимые кнопки: **«Скачать»** (в галерею телефона) и **«Отправить в Telegram»** (через бота в выбранную цель). От нажатия «Поделиться» в TikTok до отправки — не больше трёх тапов.

Приложение закрытое: пользоваться им могут только люди с приглашением. Распространяется APK-файлом, без Google Play.

## Поддерживаемый контент

| Платформа | Что поддерживается | Форматы ссылок |
| --- | --- | --- |
| TikTok | Публичные видео | `tiktok.com/@user/video/<id>`, `vm.tiktok.com/<code>`, `vt.tiktok.com/<code>`, `m.tiktok.com/v/<id>` |
| Instagram | Публичные Reels и посты с одним видео | `instagram.com/reel/<code>`, `instagram.com/reels/<code>`, `instagram.com/p/<code>` (если внутри видео) |

Не поддерживаются: фото и карусели, сторис, прямые эфиры, приватные аккаунты, другие платформы. Для них — понятная ошибка `unsupported_url` или `unsupported_content`.

## Роли

| Роль | Кто | Возможности |
| --- | --- | --- |
| Пользователь | Любой, кто вошёл по инвайту | Скачивание, отправка в свои цели, история, настройки |
| Администратор | Владелец (Max) | Всё, что пользователь, плюс: инвайты, список пользователей, блокировка, статус системы, cookies Instagram, управление воркерами |

Первый администратор создаётся командой CLI ядра при первом запуске (`core admin bootstrap`), которая печатает одноразовый инвайт с ролью admin.

## Сценарии

### С1. «Поделиться» из TikTok или Instagram

1. Пользователь в TikTok/Instagram нажимает «Поделиться» → выбирает Quoker.
2. Поверх исходного приложения открывается sheet «Видео»; из текста интента извлекается ссылка.
3. Пока ядро резолвит ссылку — скелетон; затем превью: обложка, платформа, автор, описание (до 3 строк), длительность, размер, отметка «без водяного знака» для TikTok.
4. Две независимые кнопки: «Скачать» и «Отправить в Telegram». Можно нажать обе, в любом порядке.
5. Sheet можно закрыть в любой момент: скачивание продолжится в фоне, отправка — на сервере.

### С2. Ссылка вручную

1. Главный экран: поле ссылки, кнопка вставки, чип «Вставить ссылку из буфера», если в буфере подходящая ссылка.
2. «Открыть видео» → тот же sheet «Видео».

### С3. Скачать

1. «Скачать» → кнопка превращается в прогресс «Скачивается · N%» с отменой.
2. Ядро при необходимости ставит задачу воркеру на скачивание; приложение ждёт готовности, затем качает файл с ядра с докачкой.
3. Файл сохраняется в `Movies/Quoker/` через MediaStore, сразу виден в галерее. Snackbar «Сохранено в галерею» с действием «Открыть».
4. Повторное скачивание того же видео — диалог «Уже скачано. Скачать ещё раз?».

### С4. Отправить в Telegram

1. «Отправить в Telegram» → sheet «Куда отправить»: последняя использованная цель первой, затем остальные по алфавиту.
2. Поле «Подпись» — по умолчанию ссылка на оригинал; можно редактировать или очистить.
3. Переключатель «Подписать „от @username“» — виден и по умолчанию включён только для групп; для каналов и лички не показывается.
4. «Отправить в „<цель>“» → статус в sheet «Видео»: в очереди → отправляется → «Отправлено в „<цель>“» / ошибка с причиной и «Повторить».
5. Пустой список целей → пустое состояние с инструкцией, как добавить бота в канал или группу.

### С5. Первый запуск

1. Экран «Вход по приглашению»: код формата `XXXX-XXXX`.
2. Экран «Привяжите Telegram»: кнопка «Открыть бота в Telegram» (deep link с одноразовым токеном, действует 10 минут), статус «Ждём подтверждения…», инструкция про добавление бота в каналы и группы.
3. После привязки — главный экран. Без привязанного Telegram приложение работает только на скачивание; кнопка «Отправить» ведёт на экран привязки.

### С6. Добавление цели

1. Пользователь добавляет бота в группу или назначает администратором канала с правом публикации.
2. Бот видит, кто это сделал, и записывает цель в список этого пользователя. Если человек не привязан к Quoker — бот пишет в чат, что сначала нужно привязать приложение, и цель не создаёт.
3. Другой участник того же чата может подключить цель себе командой `/connect` в чате (проверяются его права).
4. Цель появляется в приложении при следующем обновлении списка.

### С7. История

Список последних действий: что резолвилось, скачивалось, куда отправлялось, с ошибками. Из истории можно скачать снова, отправить снова, повторить неудачную отправку, открыть оригинал.

### С8. Администрирование

Через бота (команды в личке) и через раздел «Администрирование» в настройках приложения: создать инвайт, список пользователей, заблокировать/разблокировать, статус системы (воркеры, очередь, диск, версии), загрузить cookies Instagram, разрешить/отозвать воркер.

## Функциональные требования

| ID | Область | Требование |
| --- | --- | --- |
| F-1 | Приём ссылки | `ACTION_SEND` с `text/plain`; Quoker виден в меню «Поделиться» |
| F-2 | Приём ссылки | Из текста интента извлекается первый URL поддерживаемого домена (TikTok добавляет к ссылке свой текст) |
| F-3 | Приём ссылки | Клиентская проверка домена до запроса; неподдерживаемая ссылка → ошибка без сетевого запроса |
| F-4 | Приём ссылки | Чип «Вставить из буфера» на главном экране, если буфер содержит поддерживаемую ссылку |
| F-5 | Резолв | Ядро нормализует ссылку, разворачивает короткие, вычисляет `video_id = <platform>:<native_id>` |
| F-6 | Резолв | Метаданные: платформа, автор, описание, длительность, размер, ширина/высота, обложка |
| F-7 | Резолв | Повторный запрос того же видео в течение 24 ч отдаётся из кэша ядра |
| F-8 | Скачивание | Файл качается с ядра с прогрессом, отменой и докачкой (HTTP Range) |
| F-9 | Скачивание | Сохранение в `Movies/Quoker/`, имя `<platform>_<author>_<native_id>.mp4` |
| F-10 | Скачивание | Фоновое скачивание через WorkManager с уведомлением; переживает закрытие sheet |
| F-11 | Скачивание | Для TikTok — всегда версия без водяного знака |
| F-12 | Отправка | Выбор цели из личного списка; последняя использованная — первой |
| F-13 | Отправка | Подпись: по умолчанию ссылка на оригинал, редактируемая, до 1024 символов |
| F-14 | Отправка | В группах по умолчанию добавляется «от @username» (или имя, если username нет), переключатель отключает; в каналах и личке — никогда |
| F-15 | Отправка | Отправляет воркер через Bot API `sendVideo`, файл не проходит через телефон |
| F-16 | Отправка | Видео больше 50 МБ: воркер берёт лучший формат до 50 МБ; если такого нет — ошибка `too_large` |
| F-17 | Отправка | Статусы: `queued` → `sending` → `sent` / `failed` с кодом причины; повтор из UI |
| F-18 | Аккаунт | Регистрация по инвайту; сессия на устройство; выход отзывает сессию |
| F-19 | Аккаунт | Привязка Telegram через deep link с одноразовым токеном; отвязка из настроек |
| F-20 | Цели | Личный список целей; скрыть/показать у себя; обновить вручную |
| F-21 | Цели | Неактивные цели (бот удалён, права отозваны, пользователь вышел) показываются серыми с причиной и недоступны для выбора |
| F-22 | Цели | Цель «Сохранённое в боте» (личка с ботом) есть у каждого привязанного пользователя |
| F-23 | История | Последние 200 действий, пагинация курсором, группировка по дням; действия из истории |
| F-24 | Обновления | Проверка новой версии при запуске (не чаще раза в сутки); диалог; скачивание APK с ядра и запуск установщика |
| F-25 | Обновления | `min_supported_version_code`: ниже него приложение показывает экран «Обновите приложение» |
| F-26 | Админ | Инвайты: создание (одноразовые, срок 7 дней), список, отзыв |
| F-27 | Админ | Пользователи: список, блокировка/разблокировка; блокировка отзывает все сессии, разблокировка возвращает их (выход из аккаунта — окончательный) |
| F-28 | Админ | Статус: подключённые воркеры, версии, очередь, ошибки по платформам за 24 ч, диск ядра |
| F-29 | Админ | Загрузка cookies Instagram (файл Netscape-формата) через бота или приложение |
| F-30 | Админ | Воркеры: разрешить по отпечатку сертификата, отозвать, назначить опрашивающий апдейты |
| F-31 | Уведомления | Админу через бота: недоступность ядра/воркера, рост ошибок, диск, истечение сертификатов, ежедневная сводка (см. `docs/11-nfr-security.md`) |

## Вне рамок продукта

Фото и карусели, сторис, другие платформы, пакетная обработка, отложенная отправка, редактирование видео, iOS, Google Play, публичная регистрация.
