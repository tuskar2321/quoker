# 05. Модель данных ядра

SQLite в режиме WAL, один файл `/opt/app/data/quoker.db`. Схема — `core/migrations/` (`NNNN_<имя>.sql`, номер = версия), применяется ядром при старте (встроена через `embed`, версия в `PRAGMA user_version`). Время — `INTEGER` unix ms UTC.

## Таблицы

| Таблица | Назначение | Ключевые правила |
| --- | --- | --- |
| `users` | Пользователи | `tg_user_id` уникален: один Telegram — один аккаунт Quoker |
| `invites` | Приглашения | Хранится только SHA-256 нормализованного кода (без дефиса) и `code_prefix` — первые 4 символа для маски в списке; одноразовые; срок 7 дней по умолчанию |
| `sessions` | Сессии устройств | Хранится только SHA-256 токена; блокировка пользователя ставит `revoked_at` всем с `revoke_reason = blocked`, разблокировка снимает отзыв только с них; `logout` — окончательный |
| `link_tokens` | Токены привязки Telegram | TTL 10 минут, одноразовые |
| `targets` | Цели отправки | Уникальность `(owner_user_id, chat_id)`: один чат может быть целью у нескольких пользователей, но у каждого — своя запись |
| `videos` | Кэш метаданных и состояния файла | TTL 24 ч от последнего обращения; файл и обложка удаляются вместе с записью |
| `video_aliases` | Нормализованные исходные ссылки → `video_id` | Короткие ссылки не резолвятся повторно |
| `tasks` | Очередь задач для воркеров | Одна активная задача на `dedup_key`; выборка по приоритету |
| `sends` | Отправки | Идемпотентность по `(user_id, idempotency_key)` |
| `history` | Действия пользователя | Хранится 90 дней, потом удаляется |
| `history_videos` | Метаданные видео для истории | Живут дольше кэша `videos` |
| `workers` | Разрешённые воркеры | Отзыв = `status = revoked` + разрыв стрима |
| `bot_updates` | Обработанные `update_id` | Идемпотентность апдейтов; чистится старше 7 дней |
| `settings` | Секреты и настройки | `bot_token`, `instagram_cookies`, `bot_username`, `admin_chat_id`, `poller_worker_id`, `min_supported_version_code` |
| `app_releases` | Версии APK | Последняя по `version_code` отдаётся в `/v1/app/version` |
| `rate_limits` | Счётчики лимитов | Окно — календарный час |

## Файлы на диске ядра

```
/opt/app/cache/files/<sha1(video_id)>.mp4
/opt/app/cache/thumbs/<sha1(video_id)>.jpg
/opt/app/cache/partial/<sha1(video_id)>.part     — недокачанные загрузки от воркера
/opt/app/releases/quoker-<version_name>.apk
/opt/app/backups/quoker-<YYYYMMDD-HHMM>.db
```

- Лимит кэша — 3 ГБ (`CACHE_MAX_BYTES`). При превышении удаляются файлы с наименьшим `last_access_at`, пока не освободится 10% лимита; файлы с активной раздачей или отправкой не трогаются.
- Фоновая чистка раз в 10 минут: просроченные `videos`, сироты на диске, `partial` старше часа.

## Приоритеты очереди

| Тип | Приоритет | Почему |
| --- | --- | --- |
| `bot_call` | 30 | Ответы бота и проверки прав блокируют пользователя |
| `resolve` | 20 | Пользователь ждёт превью |
| `send_video` | 10 | Пользователь уже нажал, но может закрыть экран |
| `download` | 0 | Самая тяжёлая, идёт в фоне |

## Секреты в БД

Токен бота и cookies Instagram хранятся в `settings` в открытом виде: сервер ядра надёжен, а файл БД доступен только пользователю контейнера (`0600`). Бэкапы содержат эти секреты — на ПК они лежат на зашифрованном диске (`docs/10-deploy.md`).
