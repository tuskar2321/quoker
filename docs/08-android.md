# 08. Android-клиент

Пакет `app.quoker`, `minSdk 26`, `targetSdk`/`compileSdk` — последние стабильные. Только портретная ориентация, только тёмная тема (`docs/09-design.md`). Распространение — подписанный APK.

## Модули

```
android/
  app/                    Application, MainActivity, ShareActivity, навигация, DI-граф
  core/designsystem/      QuokerTheme, цвета, типографика, компоненты (кнопки, sheet, чипы, строки списков)
  core/network/           Retrofit API (по api/openapi.yaml), OkHttp, интерсепторы, модели
  core/data/              Репозитории, DataStore (сессия), Room (кэш истории и целей)
  core/download/          WorkManager-воркеры скачивания, MediaStore, уведомления
  core/update/            Проверка и установка обновлений APK
  core/common/            Url-проверка (те же векторы, что в ядре), результаты, диспетчеры
  feature/onboarding/     Инвайт, привязка Telegram
  feature/home/           Главный экран
  feature/video/          Sheet «Видео» (общий для Share и главного)
  feature/send/           Sheet «Куда отправить»
  feature/history/        История
  feature/settings/       Настройки + администрирование
```

## Точки входа

- **MainActivity** — обычный запуск; навигация: онбординг (если нет сессии) → главный → история / настройки / админка.
- **ShareActivity** — `intent-filter` `ACTION_SEND`, `text/plain`; прозрачная тема, `excludeFromRecents="true"`, своя `taskAffinity`, чтобы открываться поверх TikTok/Instagram и возвращать в них после закрытия. Показывает только sheet «Видео» (и при необходимости «Куда отправить»). Без сессии — короткий экран «Сначала войдите в Quoker» с кнопкой открыть приложение.
- Извлечение ссылки: `EXTRA_TEXT`, затем `EXTRA_SUBJECT`; первая подходящая по векторам из `core/common`.

## Сессия и сеть

- `session_token` — в DataStore, зашифрованный AEAD-ключом Tink, ключ в Android Keystore.
- OkHttp: таймауты 10/30/30 с; вход по коду приглашения ограничен 10 с на весь запрос, после чего показывается ошибка сети; интерсептор добавляет `Authorization`, `X-Quoker-Version-Code`, `X-Device-Id`.
- `401` → сброс сессии и переход на онбординг; `426` → экран «Обновите приложение»; `403 user_blocked` → экран «Доступ закрыт».
- Ошибки API → `QuokerError(code, message, retryable)`; тексты для UI — из `strings.xml` по `code`, `message` сервера — запасной вариант.

## Экраны и состояния

Макеты — `docs/design/mockups/*.dc.html` (утверждены). Для состояний без макета — те же токены и компоненты.

### Главный (`Main.dc.html`)

- Шапка: лягушка 32 px + «quoker», кнопка настроек.
- Поле ссылки с кнопкой «Вставить»; чип «Вставить ссылку из буфера» — только если буфер содержит поддерживаемую ссылку (читается в `onResume` после получения фокуса окна; на Android 12+ система показывает тост — это ожидаемо).
- «Открыть видео» → sheet «Видео».
- «Недавние»: 3 последних элемента истории, «Вся история».
- Состояния: пусто (нет истории — блок «Недавние» скрыт), есть ссылка в буфере, есть история, нет сети (баннер).

### Sheet «Видео» (`Video`, `Downloading`, `Error`)

| Состояние | Что видно |
| --- | --- |
| Загрузка | Скелетон обложки и текста, кнопки неактивны |
| Готово | Обложка 112×198 с длительностью, чип платформы, автор, описание (3 строки), «N МБ · без водяного знака», кнопки «Скачать» и «Отправить в Telegram», ссылка и «Открыть оригинал» |
| Скачивается | Кнопка «Скачать» → прогресс «Скачивается · N%» с отменой; подсказка «Можно закрыть — скачивание продолжится в фоне» |
| Скачано | Кнопка «Скачать» → «Сохранено · Открыть» |
| Отправляется / Отправлено / Ошибка отправки | Кнопка «Отправить» → статус «Отправляется в „X“…» / «Отправлено в „X“ · Ещё» / «Не отправлено · Повторить» |
| Ошибка резолва | Иконка, заголовок, текст причины по коду, «Попробовать снова», «Закрыть» |
| Нет Telegram | «Отправить в Telegram» ведёт на экран привязки |

Обе кнопки независимы: каждая держит своё состояние, нажатие одной не блокирует другую.

### Sheet «Куда отправить» (`Send.dc.html`)

- Список активных целей (последняя — первой, с пометкой «последняя»), неактивные — серыми внизу с причиной, скрытые не показываются.
- Поле «Подпись», переключатель «Подписать „от @username“» (только для групп).
- Кнопка «Отправить в „X“»; `Idempotency-Key` генерируется при открытии sheet, повтор нажатия — тот же ключ.
- Пустое состояние: «Пока некуда отправлять» + инструкция + «Обновить список».

### История (`History.dc.html`)

Группировка «Сегодня / Вчера / дата», карточка: обложка 64×88, автор, «Платформа · длительность · размер», бейджи действий («Скачано», «→ Цель», «Ошибка отправки»), кнопки «Скачать снова / Отправить / Повторить». Бесконечная прокрутка курсором; кэш первой страницы в Room для мгновенного показа.

### Настройки (`Settings.dc.html`)

Telegram (аккаунт, «Отвязать» с подтверждением), «Куда отправлять» (цели с переключателями видимости, неактивные с причиной, «Обновить», ссылка на инструкцию), «Приложение» (версия, «Проверить обновления»), «Выйти» (с подтверждением). Для `role = admin` — пункт «Администрирование» первой строкой группы «Приложение»; версия и «Проверить обновления» — одной строкой.

### Администрирование (`AdminStatus`, `AdminInvites`, `AdminUsers`)

Вход — пункт «Администрирование» в группе «Приложение» настроек, только для `role = admin`.

- **Администрирование** (`AdminStatus.dc.html`): сверху алерт-карточка, если есть активная проблема (Instagram требует вход, нет воркеров, диск > 80%); сетка 2×2 «Состояние» — воркеры (онлайн, опрашивающий), очередь, ошибки за 24 ч по платформам, диск ядра с полосой; группа «Управление» — «Приглашения», «Пользователи», «Cookies Instagram» с кнопкой «Загрузить» (SAF → `PUT /v1/admin/instagram-cookies`, дата обновления красным, если старше 14 дней), «Воркеры».
- **Приглашения** (`AdminInvites.dc.html`): переключатель роли, срок действия, «Создать приглашение»; новый код — лаймовая карточка с кодом крупно, «Код показывается один раз», «Скопировать» и «Поделиться»; список выданных (код замаскирован, роль, срок, «Отозвать»; использованные — серым с @username).
- **Пользователи** (`AdminUsers.dc.html`): счётчики, карточки пользователей (аватар-инициал, @username или имя, последний визит, число целей), «Заблокировать» / «Разблокировать» с подтверждением; свой аккаунт без действий; пояснение, что блокировка завершает все сессии.
- **Воркеры** (макета нет, по образцу «Пользователей»): id, онлайн/офлайн, версии воркера и yt-dlp, срок сертификата, отметка «опрашивает», «Отозвать»; «Разрешить воркер» — ввод id и отпечатка.
- Баннер на главном экране для админа, если нет ни одного воркера дольше 5 минут.

### Онбординг (`Invite.dc.html`, `Telegram.dc.html`)

- Инвайт: поле с автоформатированием `XXXX-XXXX`, верхний регистр; ошибки «Код не подошёл».
- Telegram: шаги, «Открыть бота в Telegram» (Intent на deep link; если Telegram не установлен — открывается браузер), статус «Ждём подтверждения…» с опросом раз в 2 с, «Ссылка истекла — получить новую». «Пропустить» — ведёт на главный, отправка будет недоступна до привязки.

## Скачивание

- `DownloadWorker` (WorkManager, expedited + foreground service типа `dataSync`): `prepare` → опрос задачи → GET файла с Range в `cacheDir`, затем копирование в MediaStore (`Movies/Quoker`, `IS_PENDING`), затем `POST /downloaded`.
- Уведомление канала «Загрузки»: прогресс, отмена; по завершении — «Сохранено» с открытием видео.
- Разрешения: `POST_NOTIFICATIONS` (Android 13+, запрашивается при первом скачивании), `WRITE_EXTERNAL_STORAGE` только `maxSdkVersion=28`.
- Прогресс в sheet — через `WorkManager.getWorkInfoByIdFlow`.

## Отправка

`POST /v1/sends` → опрос `GET /v1/sends/{id}` раз в секунду, пока sheet открыт; если закрыт — опрос прекращается, результат видно в истории.

## Обновления

- При старте MainActivity, не чаще раза в сутки: `GET /v1/app/version`. Новее текущей → диалог с changelog: «Обновить» / «Позже».
- Скачивание APK через `DownloadManager` или OkHttp в `cacheDir`, проверка `sha256`, установка через `PackageInstaller`/`ACTION_VIEW` + `FileProvider`; разрешение `REQUEST_INSTALL_PACKAGES` (системный экран «Разрешить установку из этого источника» при первом обновлении).
- `version_code` < `min_supported_version_code` → полноэкранный «Обновите приложение» без возможности закрыть.

## Строки

Все тексты из макетов и `docs/06-telegram-bot.md` — в `values/strings.xml` (русский — язык по умолчанию). Ошибки — `error_<code>`. Количества — `plurals`. Других языков нет, поэтому приложение и его activity всегда разрешают ресурсы в русской конфигурации, независимо от языка системы: иначе `plurals` склоняются по правилам системной локали (на английской системе получается «7 дня»).

## Сборка

- Gradle Kotlin DSL, version catalog `gradle/libs.versions.toml`.
- `release` подписывается keystore из секретов CI; `versionCode` = номер сборки CI, `versionName` из тега `app-v<x.y.z>`.
- R8 включён для `release`; правила для kotlinx.serialization и Retrofit.
